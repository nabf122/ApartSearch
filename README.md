# ApartSearch

국토교통부 아파트 및 연립·다세대주택 매매 실거래 정보를 검색하는 React 앱입니다. Node.js 20 이상을 사용하세요.

## 개발 실행

1. `npm ci`
2. `.env.server.example`을 `.env.server.local`로 복사하고 `APART_API_SERVICE_KEY`에 공공데이터포털의 **Decoding 인증키**를 입력합니다.
3. 터미널 하나에서 `npm run server` (127.0.0.1:3001)
4. 다른 터미널에서 `npm start` (localhost:3000)

기존 인증키는 로컬 `.env.server.local`로 이전했습니다. 이 파일은 Git에서 제외됩니다. 운영에서는 서버 환경변수로 설정하세요. `REACT_APP_` 환경변수에 인증키를 넣으면 브라우저 번들에 노출되므로 사용하지 않습니다. 이미 커밋된 인증키는 과거 Git 기록에 남으므로 공공데이터포털에서 재발급한 뒤 로컬 값을 교체하세요.

## 검색

주택 유형은 전체, 아파트, 빌라 중에서 선택할 수 있으며 기본값은 아파트입니다. 빌라는 연립·다세대주택 매매 실거래를 조회합니다. 전체는 두 유형을 합산하며, 빌라와 전체를 사용하려면 공공데이터포털에서 [연립다세대 매매 실거래가 API](https://www.data.go.kr/data/15126467/openapi.do) 활용 권한이 필요합니다.

시·도와 선택 항목인 시·군·구, 계약 연도와 월, 페이지당 건수(20·50·100·200)를 선택합니다. 계약월 기본값은 지난달입니다. 시군구 선택 시 시도 코드 2자리와 시군구 코드 3자리를 합쳐 법정동코드 앞 5자리로 조회합니다. 시군구 전체 선택 시 서버가 해당 시도의 시군구별 조회 결과와 건수를 합산해 페이지를 구성합니다. 전체 조회는 여러 API 요청을 수행하므로 더 오래 걸릴 수 있습니다. 공공데이터 요청은 1.1초 간격으로 순차 실행하며 성공 응답은 5분간 메모리에 캐시합니다. 페이지 이동은 마지막으로 검색한 조건을 유지하며, 새 검색은 1페이지로 시작합니다. 컬럼 정렬은 현재 페이지에 적용됩니다. 응답의 XML/JSON, 단건/다건/빈 결과를 서버에서 정규화합니다.

지역 목록은 `data/국토교통부_법정동코드_20260813.csv`의 존재하는 법정동을 기준으로 생성합니다. CSV 교체 시 `npm run generate:regions`로 `src/regions.json`을 갱신합니다. 구가 있는 시의 상위 코드는 제외하며 세종시는 전체 지역으로 처리합니다.

## 검증 및 운영

- UI 테스트: `npm test -- --watchAll=false`
- 서버 테스트: `npm run test:server`
- 빌드: `npm run build`
- 빌드 후 `npm run server`로 정적 화면과 API를 함께 제공합니다.

서버는 기본적으로 로컬 주소에 바인딩합니다. 외부 서비스로 운영할 때는 HTTPS 리버스 프록시를 연결하고 API 호출 제한을 적용하세요. 서버는 외부 API 요청에 15초 제한을 적용하고 인증키나 원본 오류를 응답에 포함하지 않습니다.
